按季节探索

秋

从山间染到村落的红叶

红叶从北海道的山间开始，慢慢向南推移。京都寺院庭园染成红黄两色，大约在11月下旬。

看点

  1. 日光（栃木）

    中禅寺湖和伊吕波坂在10月中旬至下旬最美，东照宫周边则在11月上旬。道路容易拥堵，建议清晨出发。

  2. 东福寺（京都）

    从通天桥俯瞰，整个溪谷被红叶染红。最佳观赏期为11月下旬。

  3. 奥入濑溪流（青森）

    可以沿着溪流，在染成黄色和红色的树下漫步。最佳观赏期为10月中旬至下旬。

  4. 香岚溪（爱知）

    约4,000棵枫树装点溪谷，是东海地区首屈一指的红叶名所。11月中旬至下旬最美，夜间有灯光点亮。

旅行备忘

最佳时期
10月～12月上旬
推荐地点
日光（栃木）、东福寺（京都）、奥入濑溪流（青森）
穿着
10月穿长袖衬衫，11月需要夹克或毛衣。山区比市区更冷。

旅行小贴士

红叶由北向南、从山顶向山脚推进。名所建议在平日或清晨前往。11月的京都住宿紧张，请尽早预订。
