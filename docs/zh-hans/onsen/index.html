不只是风景的日本

温泉

温泉遍布日本各地。可以边泡汤边赏雪，有些地方还能遇见泡温泉的野生猴子。

火山众多的日本有近3,000处温泉地。漫步温泉街，在旅馆享受泡汤和美食的一晚，是旅途中格外特别的时光。

要点

  1. 草津温泉（群马）

    温泉街中心是热气腾腾的“汤畑”，还可以观看用木板搅动泉水的传统“揉汤”表演。

  2. 别府温泉（大分）

    涌出量居日本第一。巡游各色源泉的“地狱巡礼”很受欢迎。

  3. 城崎温泉（兵库）

    穿着浴衣和木屐，沿柳树成荫的河边漫步，巡游七处外汤的温泉街。

  4. 地狱谷野猿公苑（长野）

    可以近距离观察泡温泉的野生猴子。人泡的温泉请到附近的涩温泉、汤田中温泉。

旅行备忘

旅行小贴士

进入浴池前先清洗身体，毛巾不要浸入水中。长发请扎起来。有些设施不接待有纹身的客人，请事先确认是否有包场浴池或可接待的设施。
