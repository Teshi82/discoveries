6天

北国大地自驾

租车穿行花田与丘陵，再前往世界自然遗产知床的原始自然。

从札幌出发向东，沿途景色从花田变为湖泊，再到原始森林的自驾路线。全程约600公里。最后在女满别机场还车，就不必原路返回。

行程

  1. 札幌（第1天）

    游览市区，品尝味噌拉面和海鲜。第二天早上租车出发。

  2. 富良野、美瑛（第2～3天）

    从札幌开车约2小时。悠闲地游览薰衣草田、拼布之丘和青池。

  3. 阿寒湖（第4天）

    从美瑛出发约4小时的长途车程。入住以绿球藻闻名的湖畔温泉街，还可以接触阿伊努文化。

  4. 知床（第5～6天）

    从阿寒湖出发约2小时30分钟。漫步知床五湖或乘观光船，感受原始的自然。从宇登吕到女满别机场约2小时。

旅行备忘

最佳时期
花期在6月下旬至8月（薰衣草在7月）。红叶在9月下旬至10月。
交通方式
租车自驾。日本靠左行驶。持外国驾照驾驶需要国际驾照；部分国家和地区则需要驾照的日文翻译件。

旅行小贴士

清晨和傍晚，虾夷鹿和北狐可能突然冲上道路。请不要投喂野生动物。有些路段加油站很少，请尽早加油。
