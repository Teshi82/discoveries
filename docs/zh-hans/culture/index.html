不只是风景的日本

传统文化

城郭、神社寺院、和服、祭典。感受代代传承的审美。

城堡、神社、寺院和祭典，至今仍在日常生活中代代相传。不只是观赏，了解礼仪并参与体验，会让旅行的印象更深刻。

要点

  1. 城堡

    保留着江户时代及更早天守的城堡，全国共有12座。代表性的有因白色外观而被称为“白鹭城”的世界遗产姬路城，以及拥有黑色天守的松本城。

  2. 神社与寺院

    在神社，先在鸟居前鞠躬，在手水舍清洗双手和口，再以二拜、二拍手、一拜的方式参拜。在寺院不拍手，安静地合掌。

  3. 祭典

    7月的京都祇园祭、8月的青森睡魔祭、春秋两季的高山祭等。花车和神轿在街上巡游。

  4. 体验

    茶道、和服穿着、坐禅、住宿寺院的宿坊等。在高野山可以参加早课。
