山阳、四国

濑户内

以桥与船相连，游走于平静的大海和岛屿之间。

被本州、四国、九州环抱的濑户内海上，散布着大大小小的岛屿。这里少雨温暖，海边的小镇保留着古老的港口和街景。自行车、船，还有当代艺术，是这片地区旅行的主角。

看点

  1. 岛波海道

    连接广岛县尾道与爱媛县今治的自行车道，全长约70公里，经由6座岛屿和桥梁。租借的自行车可以在途中的岛上归还。

  2. 直岛

    以安藤忠雄设计的地中美术馆，以及海边草间弥生的《南瓜》闻名的艺术之岛。从冈山县宇野港乘渡轮约20分钟。

  3. 宫岛、严岛神社

    涨潮时，朱红色的大鸟居和社殿仿佛浮在海上；退潮时可以走到鸟居旁边。已被列入世界遗产。

  4. 仓敷美观地区

    柳树成荫的水渠两旁，白墙仓库连绵成片。日本第一座私立西洋美术馆——大原美术馆也在这里。

旅行备忘

最佳时期
最舒适的是春季（3月至5月）和秋季（10月至11月）。每三年举办一次的濑户内国际艺术节期间，各岛更加热闹。
交通
从东京乘新干线到冈山约3小时20分钟，到广岛约4小时。前往各岛可从各地港口乘渡轮或高速船。
建议停留
3～5天。若想同时游览直岛和岛波海道，建议4天以上。

旅行小贴士

美术馆多在周一休馆，地中美术馆需提前预约。渡轮班次有限，请先确认回程时间。
