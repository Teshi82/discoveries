不只是风景的日本

美食

寿司、拉面、乡土料理。从路边小摊到百年老店，品尝季节与土地的味道。

日本的饮食因地域和季节而大不相同。2013年，“和食”被列入联合国教科文组织非物质文化遗产。不只是高级餐厅，车站便当、百货公司的食品卖场和便利店里也有惊喜。

要点

  1. 寿司

    从实惠的回转寿司，到师傅在眼前捏制的吧台店。吧台店一般需要预约，并以“Omakase”（主厨搭配）的方式点餐。

  2. 拉面

    札幌的味噌、博多的豚骨、东京的酱油，各地风味不同。很多店需要在门口的售票机购买餐券。

  3. 居酒屋

    一边分享小碟菜肴一边喝酒的店。有时会送上一道名为“Otoshi”的小菜，代替座位费。

  4. 乡土料理与市场

    大阪的章鱼烧、广岛的牡蛎、北海道的海鲜盖饭。各地的市场从清晨起就能品尝当地风味。

旅行备忘

旅行小贴士

不需要给小费。街头小吃请在店门口或指定区域享用，不要边走边吃。有过敏或素食需求的人请事先告知店家，蔬菜料理也可能使用鱼高汤。
