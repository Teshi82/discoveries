日本北部

北海道

夏有花海丘陵，冬有粉雪。四季各有不同面貌的北方大地。

北海道约占日本国土面积的五分之一，辽阔的天空、笔直的道路和原始的自然是它的魅力所在。夏季凉爽，冬季积雪深厚。各景点相距较远，建议锁定区域来规划行程。

看点

  1. 富良野、美瑛

    7月中旬迎来盛花期的薰衣草田，以及农田拼出图案的“拼布之丘”。美瑛的“青池”也很受欢迎。

  2. 知床

    2005年被列入世界自然遗产的半岛。夏季可漫步知床五湖或乘坐观光船，冬季可以看到鄂霍次克海的流冰。

  3. 二世谷

    吸引全球滑雪爱好者的粉雪胜地。夏季可以一边眺望羊蹄山，一边体验漂流和徒步。

  4. 札幌、小樽

    2月上旬的“札幌冰雪节”，以及石造仓库林立的小樽运河。味噌拉面、海鲜等美食也十分丰富。

旅行备忘

最佳时期
花田与丘陵风光在6月至8月，雪景与冬季运动在12月至次年3月。红叶9月中旬从大雪山开始。
交通
从东京（羽田）到新千岁机场约1小时30分钟。从机场乘快速列车到札幌约40分钟。
建议停留
4～7天。一次旅行建议集中在道央、道东等1～2个区域。

旅行小贴士

实际距离比地图上看起来远。从札幌开车到富良野约2小时，到知床约6小时。如果不习惯冬季雪地驾驶，请利用铁路和巴士。
