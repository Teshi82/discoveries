旅行实用信息

礼仪

电车内请避免通话。泡温泉前先洗净身体，毛巾不要浸入池中。

没有复杂的规矩。基本原则是体谅他人，不给周围的人添麻烦。拿不准的时候，跟着周围的人做就可以了。

要点

  1. 在电车和巴士上

    不要打电话，交谈请小声。背包抱在胸前，上车时排队。

  2. 脱鞋

    在旅馆、寺院和民宅，要在入口处脱鞋。进入榻榻米房间时，拖鞋也要脱掉。

  3. 垃圾

    街上几乎没有垃圾桶。请随身带一个小袋子，把垃圾带回住处再扔。

  4. 温泉与钱汤

    进入浴池前先清洗身体，毛巾不要浸入水中。浴室内禁止拍照。
