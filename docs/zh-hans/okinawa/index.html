西南诸岛

冲绳、庆良间群岛

邂逅清澈的大海与琉球文化的南方岛屿。

属亚热带气候的冲绳，曾作为琉球王国孕育出独特的文化。以那霸为据点，可以乘船前往庆良间的大海，探访本岛北部的自然，再向南延伸到八重山群岛。

看点

  1. 庆良间群岛

    从那霸泊港乘高速船，到渡嘉敷岛约35分钟，到座间味岛约50分钟。在这片国立公园的海域，有时还能与海龟同游。

  2. 首里城公园

    琉球王国的王城遗址。正殿在2019年的火灾中被烧毁，此后一直在进行复原。开放情况请查看官方网站。

  3. 冲绳美丽海水族馆

    以鲸鲨和蝠鲼畅游的大水槽“黑潮之海”而闻名。位于本岛北部，从那霸开车约2小时。

  4. 石垣岛、竹富岛

    从那霸乘飞机约1小时的八重山群岛。川平湾的景色，以及乘水牛车游览红瓦民居的竹富岛，都在等着你。

旅行备忘

最佳时期
大约4月至10月可以下海游泳。梅雨在5月上旬至6月下旬，台风多发于7月至10月。1月至3月是观鲸季节。
交通
从东京（羽田）到那霸约2小时45分钟。从那霸机场乘单轨电车“Yui Rail”到市中心约15分钟。
建议停留
3～5天。若要在离岛住宿，可再加1～2天。

旅行小贴士

台风或大浪可能导致船班停航，前往离岛的日程请安排在旅程前半段。阳光强烈，别忘了防晒，也请不要触碰珊瑚。
