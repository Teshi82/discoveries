5天

濑户内艺术与海岛

祈愿和平之地、矗立海中的大鸟居、连接岛屿的大桥与艺术。

从广岛向东，沿濑户内海前行的路线。追寻历史的城市漫步、海上的神社、骑自行车跨越的大桥、岛上的艺术，每天都有不同的乐趣。

行程

  1. 广岛（第1天）

    参观和平纪念公园和原爆圆顶馆，用一天思考和平。晚上品尝广岛烧。

  2. 宫岛（第2天）

    从广岛站乘电车和渡轮约1小时。游览严岛神社和大鸟居，乘缆车登上弥山眺望风景。

  3. 尾道、岛波海道（第3天）

    从广岛乘电车到尾道约1小时30分钟。漫步坡道与寺院之城，再骑自行车过桥前往岛屿。

  4. 直岛（第4～5天）

    经冈山前往宇野港，乘渡轮约20分钟。游览美术馆和户外作品，并在岛上住宿。

旅行备忘

最佳时期
推荐气候温和的4月至5月和10月至11月。
交通方式
搭配使用铁路、渡轮和租赁自行车。

旅行小贴士

直岛的美术馆多在周一休馆，有些设施需要预约。宫岛的景色随潮汐变化，出发前请先查看潮汐表。
