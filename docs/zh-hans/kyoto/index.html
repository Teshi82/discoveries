京都

在清晨的宁静中，漫步千年古都。

自794年起，京都作为都城长达一千多年，世界遗产的寺社、庭园和町家林立的小巷至今依然充满生机。景点分散在市内各处，按区域每天游览一处，行程会比较从容。

看点

  1. 金阁寺

    贴满金箔的舍利殿倒映在镜湖池中，是京都最具代表性的风景。晴天的上午，水中倒影格外清晰。

  2. 伏见稻荷大社

    朱红色的鸟居一路延伸到山上，这就是千本鸟居。绕稻荷山一圈约需2小时，越往上游客越少。

  3. 岚山

    竹林小径与横跨桂川的渡月桥。春天的樱花和秋天的红叶时节，整座山都染上色彩。

  4. 清水寺与东山

    从悬于山崖的“清水舞台”可以眺望市区。二年坂、产宁坂的石板路两旁保留着古老的街景。

旅行备忘

最佳时期
樱花在3月下旬至4月上旬，红叶在11月中旬至12月上旬。新绿的5月和银装素裹的冬季相对清静。
交通
从东京乘新干线约2小时15分钟。从关西国际机场乘特急“Haruka”约1小时20分钟。
建议停留
2～3天。若想顺道去奈良或宇治，可再加1天。

旅行小贴士

热门寺社建议在清晨刚开门时前往。市营巴士容易拥挤，搭配地铁、电车和步行会更顺畅。
