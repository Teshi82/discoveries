交通

城市之间乘坐新干线又快又准时。有一张交通IC卡，电车、巴士甚至购物都能搞定。

日本的铁路网四通八达，而且十分准时。城市之间乘新干线，市内乘电车和地铁，这是基本的出行方式。

要点

  1. 新干线

    东京到新大阪最快约2小时30分钟。指定席可在车站窗口、售票机或网上预订。

  2. 交通IC卡

    Suica、ICOCA等可在全国主要城市通用，也可以添加到智能手机中使用。

  3. 日本铁路通票

    面向短期停留游客、可无限次乘坐JR线路的车票。乘坐“希望号”“瑞穗号”需另付费用。

  4. 高速巴士与国内航班

    想节省费用时，夜行巴士很方便。前往北海道、九州和冲绳，乘飞机更快。
