7天

黄金路线

适合第一次来日本的旅客。一次体验都市活力、富士山与古都的经典路线。

从东京向西，沿新干线一路前行的经典路线。换乘少，即使第一次来日本也容易规划。回程从关西国际机场出境，可以省去返回东京的时间。

行程

  1. 东京（第1～3天）

    漫步浅草、涩谷、皇居周边等新旧街区。抵达当天还有时差，行程不要排得太满。

  2. 箱根、富士（第4天）

    从新宿乘特急浪漫号到箱根汤本约1小时25分钟。入住温泉旅馆，天气晴朗时可以隔着芦之湖望见富士山。

  3. 京都（第5～6天）

    从小田原乘新干线约2小时。按区域游览金阁寺、伏见稻荷、东山等地。

  4. 奈良（第6天下午）

    从京都乘电车约45分钟。半日游览东大寺大佛和小鹿漫步的奈良公园。

  5. 大阪（第7天）

    从京都乘电车约30分钟。在道顿堀边走边吃，然后从关西国际机场踏上归途。

旅行备忘

最佳时期
3月下旬至4月的樱花季，以及10月至11月的红叶季最受欢迎。夏季闷热。
交通方式
全程可乘新干线和普通列车。是否购买日本铁路通票，建议先与分段购票的价格比较后再决定。

旅行小贴士

大件行李可以用宅急便寄到下一家酒店，轻装出行（一般次日送达）。携带特大行李乘坐新干线需要事先预约座位。
