旅行实用信息

上网

eSIM或随身Wi‑Fi十分方便。机场和主要车站也提供免费Wi‑Fi。

地图、换乘查询、翻译，旅途中智能手机是最可靠的帮手。出发前先决定上网方式，这样一抵达就能使用。

要点

  1. eSIM

    出发前在线购买并设置好，抵达后即可使用。请确认手机机型是否支持。

  2. 随身Wi‑Fi

    一台可连接多部设备，适合团体和家庭出行。可以在机场领取和归还。

  3. 免费Wi‑Fi

    机场、主要车站、酒店和咖啡馆均可使用。山区和离岛有些地方信号较弱。

  4. 电源

    电压为100V，插头为两个扁脚的A型。请确认是否需要转换插头。
