本州北部

东北

溪流、白雪与温泉的热气。走进宁静的日本原风景。

位于本州北部的东北六县，拥有幽深的森林与群山、古朴的温泉和气势磅礴的夏日祭典。与大城市相比游客较少，可以慢慢感受自然与生活的风景。

看点

  1. 奥入濑溪流、十和田湖

    从十和田湖流出的溪流，全长约14公里。步道沿溪而行，一路可欣赏布满青苔的岩石和瀑布。

  2. 藏王

    冬季，被称为“雪怪”的树冰覆盖雪场，1月至2月是最佳观赏期。夏季可前往翡翠色的火山口湖“御釜”。

  3. 松岛

    日本三景之一，海湾中散布着260多座岛屿。可乘游览船环游海湾，并参观与伊达政宗有渊源的瑞岩寺。

  4. 银山温泉

    河两岸排列着大正至昭和初期木造旅馆的温泉街。煤气灯亮起的黄昏和雪季尤其有韵味。

旅行备忘

最佳时期
新绿在5月至6月，夏日祭典在8月上旬，红叶在10月，树冰在1月至2月。诀窍是按季节选择目的地。
交通
从东京乘新干线到仙台约1小时30分钟，到新青森约3小时10分钟。
建议停留
3～5天。跨县移动比较费时，一次旅行集中在2～3个县会比较轻松。

旅行小贴士

从车站出发的巴士班次较少，请事先确认时刻表，或者租车出行。8月上旬的祭典期间，请尽早预订住宿。
