山梨、静冈

富士山、富士五湖

倒映湖面，云雾缭绕。去看日本最高的山。

海拔3,776米的富士山于2013年被列入世界文化遗产。北麓的富士五湖是隔湖远眺富士山的绝佳地点。即使不登山，只要换个观景点，也能玩上一整天。

看点

  1. 河口湖

    富士五湖的门户。无风的清晨，湖面上会出现“逆富士”。北岸的大石公园可以同时欣赏花海与富士山。

  2. 新仓山浅间公园

    登上398级台阶，就能到达将五重塔与富士山收入同一画面的观景台。樱花季节尤其受欢迎。

  3. 忍野八海

    富士山的融雪经过漫长岁月渗透后涌出，形成八个池塘。池水清澈见底，令人印象深刻。

  4. 富士山五合目与登山

    登山道通常在7月上旬至9月上旬开放。设有通行费和入山限制，计划前请先确认官方网站。

旅行备忘

最佳时期
空气清澈的11月至次年2月最容易看到富士山。4月可与樱花同框，11月上旬至中旬可与红叶同框。
交通
从新宿到河口湖，乘高速巴士约1小时45分钟，乘特急“富士回游”约2小时。
建议停留
1～2天。想看清晨的富士山，建议在湖畔住一晚。

旅行小贴士

下午容易起云，清晨是最佳时机。出发前通过实时摄像头确认山的状况会更放心。
