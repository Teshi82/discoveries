按季节探索

冬

雪景与温泉

合掌造村落的积雪，露天温泉里的赏雪时光。冬季空气清澈，也是最容易看清富士山的季节。

看点

  1. 白川乡（岐阜）

    世界遗产的合掌造村落被白雪覆盖。1月至2月特定日期举行的点灯活动需要预约。

  2. 二世谷（北海道）

    12月至次年3月，世界各地的滑雪者为轻盈干爽的粉雪而来。

  3. 银山温泉（山形）

    木造旅馆林立的温泉街积满白雪，煤气灯亮起的黄昏宛如另一个世界。

  4. 地狱谷野猿公苑（长野）

    可以看到野生日本猕猴泡温泉的地方。从入口沿积雪的山路步行约30分钟。

旅行备忘

最佳时期
12月～2月
推荐地点
白川乡（岐阜）、二世古（北海道）、银山温泉（山形）
穿着
保暖大衣、手套和防滑的鞋子。室内暖气充足，方便穿脱的多层穿搭最合适。

旅行小贴士

12月29日至1月3日前后，许多商店和设施会休息。大雪可能导致列车和航班延误，行程请留出余地。
