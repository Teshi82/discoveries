7天

黃金路線

適合第一次來日本的旅客。一次體驗都市活力、富士山與古都的經典路線。

從東京向西，沿新幹線一路前行的經典路線。轉乘少，即使第一次來日本也容易規劃。回程從關西國際機場出境，可以省去返回東京的時間。

行程

  1. 東京（第1～3天）

    漫步淺草、澀谷、皇居周邊等新舊街區。抵達當天還有時差，行程不要排得太滿。

  2. 箱根、富士（第4天）

    從新宿搭特急浪漫號到箱根湯本約1小時25分鐘。入住溫泉旅館，天氣晴朗時可以隔著蘆之湖望見富士山。

  3. 京都（第5～6天）

    從小田原搭新幹線約2小時。依區域遊覽金閣寺、伏見稻荷、東山等地。

  4. 奈良（第6天下午）

    從京都搭電車約45分鐘。半日遊覽東大寺大佛與小鹿漫步的奈良公園。

  5. 大阪（第7天）

    從京都搭電車約30分鐘。在道頓堀邊走邊吃，然後從關西國際機場踏上歸途。

旅行備忘

最佳時期
3月下旬至4月的櫻花季，以及10月至11月的紅葉季最受歡迎。夏季悶熱。
交通方式
全程可搭新幹線與一般列車。是否購買日本鐵路通票，建議先與分段購票的價格比較後再決定。

旅行小提醒

大件行李可以用宅急便寄到下一間飯店，輕裝出遊（一般隔日送達）。攜帶特大行李搭乘新幹線需要事先預約座位。
