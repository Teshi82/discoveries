日本北部

北海道

夏有花海丘陵，冬有粉雪。四季各有不同風貌的北方大地。

北海道約占日本國土面積的五分之一，遼闊的天空、筆直的道路與原始的自然是它的魅力所在。夏季涼爽，冬季積雪深厚。各景點相距較遠，建議鎖定區域來規劃行程。

看點

  1. 富良野、美瑛

    7月中旬迎來盛開期的薰衣草田，以及農田拼出圖案的「拼布之丘」。美瑛的「青池」也很受歡迎。

  2. 知床

    2005年登錄為世界自然遺產的半島。夏季可漫步知床五湖或搭乘觀光船，冬季可以看到鄂霍次克海的流冰。

  3. 二世谷

    吸引全球滑雪愛好者的粉雪勝地。夏季可以一邊眺望羊蹄山，一邊體驗泛舟與健行。

  4. 札幌、小樽

    2月上旬的「札幌雪祭」，以及石造倉庫林立的小樽運河。味噌拉麵、海鮮等美食也十分豐富。

旅行備忘

最佳時期
花田與丘陵風光在6月至8月，雪景與冬季運動在12月至隔年3月。紅葉9月中旬從大雪山開始。
交通
從東京（羽田）到新千歲機場約1小時30分鐘。從機場搭快速列車到札幌約40分鐘。
建議停留
4～7天。一次旅行建議集中在道央、道東等1～2個區域。

旅行小提醒

實際距離比地圖上看起來遠。從札幌開車到富良野約2小時，到知床約6小時。如果不習慣冬季雪地駕駛，請利用鐵路與巴士。
