關西

京都

在清晨的寧靜中，漫步千年古都。

自794年起，京都作為都城長達一千多年，世界遺產的寺社、庭園與町家林立的巷弄至今依然充滿生氣。景點分散在市內各處，依區域每天遊覽一處，行程會比較從容。

看點

  1. 金閣寺

    貼滿金箔的舍利殿倒映在鏡湖池中，是京都最具代表性的風景。晴天的上午，水中倒影格外清晰。

  2. 伏見稻荷大社

    朱紅色的鳥居一路延伸到山上，這就是千本鳥居。繞稻荷山一圈約需2小時，越往上遊客越少。

  3. 嵐山

    竹林小徑與橫跨桂川的渡月橋。春天的櫻花與秋天的紅葉時節，整座山都染上色彩。

  4. 清水寺與東山

    從懸於山崖的「清水舞台」可以眺望市區。二年坂、產寧坂的石板路兩旁保留著古老的街景。

旅行備忘

最佳時期
櫻花在3月下旬至4月上旬，紅葉在11月中旬至12月上旬。新綠的5月與白雪覆蓋的冬季相對清靜。
交通
從東京搭新幹線約2小時15分鐘。從關西國際機場搭特急「Haruka」約1小時20分鐘。
建議停留
2～3天。若想順道前往奈良或宇治，可再加1天。

旅行小提醒

熱門寺社建議在清晨剛開門時前往。市營巴士容易擁擠，搭配地鐵、電車與步行會更順暢。
