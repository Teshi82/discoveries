上網

eSIM或隨身Wi‑Fi十分方便。機場和主要車站也提供免費Wi‑Fi。

地圖、轉乘查詢、翻譯，旅途中智慧型手機是最可靠的幫手。出發前先決定上網方式，這樣一抵達就能使用。

重點

  1. eSIM

    出發前線上購買並設定好，抵達後即可使用。請確認手機機型是否支援。

  2. Wi‑Fi分享器

    一台可連接多部裝置，適合團體和家庭出遊。可以在機場領取與歸還。

  3. 免費Wi‑Fi

    機場、主要車站、飯店和咖啡廳均可使用。山區和離島有些地方訊號較弱。

  4. 電源

    電壓為100V，插頭為兩個扁腳的A型。請確認是否需要轉接插頭。

旅行小提醒

建議事先下載地圖和翻譯App的離線資料，以備不時之需。拍照和使用地圖很耗電，也請準備好行動電源。
