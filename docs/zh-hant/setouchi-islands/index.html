首頁/推薦行程

5天

瀨戶內藝術與海島

祈願和平之地、矗立海中的大鳥居、連接島嶼的大橋與藝術。

從廣島向東，沿瀨戶內海前行的路線。追尋歷史的城市漫步、海上的神社、騎自行車跨越的大橋、島上的藝術，每天都有不同的樂趣。

行程

  1. 廣島（第1天）

    參觀和平紀念公園與原爆圓頂館，用一天思考和平。晚上品嚐廣島燒。

  2. 宮島（第2天）

    從廣島站搭電車和渡輪約1小時。遊覽嚴島神社與大鳥居，搭纜車登上彌山眺望風景。

  3. 尾道、島波海道（第3天）

    從廣島搭電車到尾道約1小時30分鐘。漫步坡道與寺院之城，再騎自行車過橋前往島嶼。

  4. 直島（第4～5天）

    經岡山前往宇野港，搭渡輪約20分鐘。遊覽美術館與戶外作品，並在島上住宿。

旅行備忘

最佳時期
推薦氣候溫和的4月至5月與10月至11月。
交通方式
搭配使用鐵路、渡輪與租借自行車。

旅行小提醒

直島的美術館多在週一休館，有些設施需要預約。宮島的景色隨潮汐變化，出發前請先查看潮汐表。
