首頁/推薦行程

6天

北國大地自駕

租車穿行花田與丘陵，再前往世界自然遺產知床的原始自然。

從札幌出發向東，沿途景色從花田變為湖泊，再到原始森林的自駕路線。全程約600公里。最後在女滿別機場還車，就不必原路折返。

行程

  1. 札幌（第1天）

    遊覽市區，品嚐味噌拉麵與海鮮。隔天早上租車出發。

  2. 富良野、美瑛（第2～3天）

    從札幌開車約2小時。悠閒地遊覽薰衣草田、拼布之丘與青池。

  3. 阿寒湖（第4天）

    從美瑛出發約4小時的長途車程。入住以綠球藻聞名的湖畔溫泉街，還可以接觸愛努文化。

  4. 知床（第5～6天）

    從阿寒湖出發約2小時30分鐘。漫步知床五湖或搭觀光船，感受原始的自然。從宇登呂到女滿別機場約2小時。

旅行備忘

最佳時期
花期在6月下旬至8月（薰衣草在7月）。紅葉在9月下旬至10月。
交通方式
租車自駕。日本靠左行駛。持外國駕照開車需要國際駕照；部分國家和地區則需要駕照的日文譯本。

旅行小提醒

清晨與傍晚，蝦夷鹿和北狐可能突然衝上道路。請不要餵食野生動物。有些路段加油站很少，請儘早加油。
