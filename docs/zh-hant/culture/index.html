不只是風景的日本

傳統文化

城郭、神社寺院、和服、祭典。感受代代傳承的美學。

城堡、神社、寺院與祭典，至今仍在日常生活中代代相傳。不只是觀賞，了解禮儀並參與體驗，會讓旅行的印象更深刻。

重點

  1. 城堡

    保留著江戶時代及更早天守的城堡，全國共有12座。代表性的有因白色外觀而被稱為「白鷺城」的世界遺產姬路城，以及擁有黑色天守的松本城。

  2. 神社與寺院

    在神社，先在鳥居前鞠躬，在手水舍清洗雙手和口，再以二拜、二拍手、一拜的方式參拜。在寺院不拍手，安靜地合掌。

  3. 祭典

    7月的京都祇園祭、8月的青森睡魔祭、春秋兩季的高山祭等。山車與神轎在街上遊行。

  4. 體驗

    茶道、和服穿著、坐禪、住宿寺院的宿坊等。在高野山可以參加早課。

旅行備忘

旅行小提醒

進入建築物時要脫鞋。請遵守禁止拍照的標示，不要打擾正在祈禱的人。
