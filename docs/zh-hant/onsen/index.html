不只是風景的日本

溫泉

溫泉遍布日本各地。可以邊泡湯邊賞雪，有些地方還能遇見泡溫泉的野生猴子。

火山眾多的日本有近3,000處溫泉地。漫步溫泉街，在旅館享受泡湯與美食的一晚，是旅途中格外特別的時光。

重點

  1. 草津溫泉（群馬）

    溫泉街中心是熱氣蒸騰的「湯畑」，還可以觀賞用木板攪動泉水的傳統「揉湯」表演。

  2. 別府溫泉（大分）

    湧出量居日本第一。巡遊各色源泉的「地獄巡禮」很受歡迎。

  3. 城崎溫泉（兵庫）

    穿著浴衣和木屐，沿柳樹成蔭的河邊漫步，巡遊七處外湯的溫泉街。

  4. 地獄谷野猿公苑（長野）

    可以近距離觀察泡溫泉的野生猴子。人泡的溫泉請到附近的澀溫泉、湯田中溫泉。

旅行備忘

旅行小提醒

進入浴池前先清洗身體，毛巾不要浸入水中。長髮請綁起來。有些設施不接待有刺青的客人，請事先確認是否有包場浴池或可接待的設施。
