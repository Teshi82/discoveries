山陽、四國

瀨戶內

以橋與船相連，遊走於平靜的大海與島嶼之間。

被本州、四國、九州環抱的瀨戶內海上，散布著大大小小的島嶼。這裡少雨溫暖，海邊的小鎮保留著古老的港口與街景。自行車、船，還有當代藝術，是這片地區旅行的主角。

看點

  1. 島波海道

    連接廣島縣尾道與愛媛縣今治的自行車道，全長約70公里，途經6座島嶼與橋梁。租借的自行車可以在途中的島上歸還。

  2. 直島

    以安藤忠雄設計的地中美術館，以及海邊草間彌生的《南瓜》聞名的藝術之島。從岡山縣宇野港搭渡輪約20分鐘。

  3. 宮島、嚴島神社

    漲潮時，朱紅色的大鳥居與社殿彷彿浮在海上；退潮時可以走到鳥居旁邊。已登錄為世界遺產。

  4. 倉敷美觀地區

    柳樹成蔭的水道兩旁，白牆倉庫連綿成片。日本第一座私立西洋美術館——大原美術館也在這裡。

旅行備忘

最佳時期
最舒適的是春季（3月至5月）與秋季（10月至11月）。每三年舉辦一次的瀨戶內國際藝術祭期間，各島更加熱鬧。
交通
從東京搭新幹線到岡山約3小時20分鐘，到廣島約4小時。前往各島可從各地港口搭渡輪或高速船。
建議停留
3～5天。若想同時遊覽直島與島波海道，建議4天以上。

旅行小提醒

美術館多在週一休館，地中美術館需事先預約。渡輪班次有限，請先確認回程時間。
