西南諸島

沖繩、慶良間群島

邂逅清澈大海與琉球文化的南方島嶼。

屬亞熱帶氣候的沖繩，曾以琉球王國之姿孕育出獨特的文化。以那霸為據點，可以搭船前往慶良間的大海，探訪本島北部的自然，再向南延伸到八重山群島。

看點

  1. 慶良間群島

    從那霸泊港搭高速船，到渡嘉敷島約35分鐘，到座間味島約50分鐘。在這片國立公園的海域，有時還能與海龜同游。

  2. 首里城公園

    琉球王國的王城遺址。正殿在2019年的火災中燒毀，此後持續進行復原。開放情況請查看官方網站。

  3. 沖繩美麗海水族館

    以鯨鯊與鬼蝠魟悠游的大水槽「黑潮之海」聞名。位於本島北部，從那霸開車約2小時。

  4. 石垣島、竹富島

    從那霸搭飛機約1小時的八重山群島。川平灣的景色，以及搭水牛車遊覽紅瓦民居的竹富島，都在等著你。

旅行備忘

最佳時期
大約4月至10月可以下海游泳。梅雨在5月上旬至6月下旬，颱風多發於7月至10月。1月至3月是賞鯨季節。
交通
從東京（羽田）到那霸約2小時45分鐘。從那霸機場搭單軌電車「Yui Rail」到市中心約15分鐘。
建議停留
3～5天。若要在離島住宿，可再加1～2天。

旅行小提醒

颱風或大浪可能導致船班停航，前往離島的日程請安排在旅程前半段。陽光強烈，別忘了防曬，也請不要觸碰珊瑚。
