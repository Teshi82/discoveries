本州北部

東北

溪流、白雪與溫泉的熱氣。走進寧靜的日本原風景。

位於本州北部的東北六縣，擁有幽深的森林與群山、古樸的溫泉與氣勢磅礴的夏日祭典。與大城市相比遊客較少，可以慢慢感受自然與生活的風景。

看點

  1. 奧入瀨溪流、十和田湖

    從十和田湖流出的溪流，全長約14公里。步道沿溪而行，一路可欣賞布滿青苔的岩石與瀑布。

  2. 藏王

    冬季，被稱為「雪怪」的樹冰覆蓋雪場，1月至2月是最佳觀賞期。夏季可前往翡翠色的火山口湖「御釜」。

  3. 松島

    日本三景之一，海灣中散布著260多座島嶼。可搭遊覽船環遊海灣，並參觀與伊達政宗有淵源的瑞巖寺。

  4. 銀山溫泉

    河兩岸排列著大正至昭和初期木造旅館的溫泉街。瓦斯燈亮起的黃昏與雪季尤其有韻味。

旅行備忘

最佳時期
新綠在5月至6月，夏日祭典在8月上旬，紅葉在10月，樹冰在1月至2月。訣竅是依季節選擇目的地。
交通
從東京搭新幹線到仙台約1小時30分鐘，到新青森約3小時10分鐘。
建議停留
3～5天。跨縣移動比較費時，一次旅行集中在2～3個縣會比較輕鬆。

旅行小提醒

從車站出發的巴士班次較少，請事先確認時刻表，或是租車出遊。8月上旬的祭典期間，請儘早預訂住宿。
