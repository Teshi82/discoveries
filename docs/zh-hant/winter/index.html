依季節探索

冬

雪景與溫泉

合掌造聚落的積雪，露天溫泉裡的賞雪時光。冬季空氣清澈，也是最容易看清富士山的季節。

看點

  1. 白川鄉（岐阜）

    世界遺產的合掌造聚落被白雪覆蓋。1月至2月特定日期舉行的點燈活動需要預約。

  2. 二世谷（北海道）

    12月至隔年3月，世界各地的滑雪客為輕盈乾爽的粉雪而來。

  3. 銀山溫泉（山形）

    木造旅館林立的溫泉街積滿白雪，瓦斯燈亮起的黃昏宛如另一個世界。

  4. 地獄谷野猿公苑（長野）

    可以看到野生日本獼猴泡溫泉的地方。從入口沿積雪的山路步行約30分鐘。

旅行備忘

最佳時期
12月～2月
推薦景點
白川鄉（岐阜）、二世谷（北海道）、銀山溫泉（山形）
穿著
保暖大衣、手套與防滑的鞋子。室內暖氣充足，方便穿脫的洋蔥式穿搭最合適。

旅行小提醒

12月29日至1月3日前後，許多商店與設施會休息。大雪可能導致列車與航班延誤，行程請留些餘裕。
