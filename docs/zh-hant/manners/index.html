禮儀

電車內請避免通話。泡溫泉前先洗淨身體，毛巾不要浸入池中。

沒有複雜的規矩。基本原則是體貼他人，不造成周圍的人困擾。拿不定主意的時候，跟著周圍的人做就可以了。

重點

  1. 在電車和巴士上

    不要講電話，交談請小聲。背包抱在胸前，上車時排隊。

  2. 脫鞋

    在旅館、寺院和民宅，要在入口處脫鞋。進入榻榻米房間時，拖鞋也要脫掉。

  3. 垃圾

    街上幾乎沒有垃圾桶。請隨身帶一個小袋子，把垃圾帶回住處再丟。

  4. 溫泉與錢湯

    進入浴池前先清洗身體，毛巾不要浸入水中。浴室內禁止拍照。

旅行小提醒

請不要擅自拍攝他人或私人土地。京都祇園有些私人道路禁止進入與拍照。
