付款

信用卡和行動支付已相當普及，但地方的小店和寺院神社有時只收現金。

貨幣是日圓。無現金支付日益普及，但仍有只能使用現金的場合。兩種都準備會比較安心。

重點

  1. 現金

    小餐館、寺社的參拜費、地方巴士等，有時需要使用現金。

  2. ATM

    便利商店和郵局的ATM可以用海外發行的卡片提領日圓。

  3. 刷卡與行動支付

    飯店、百貨公司和連鎖店基本上都能使用。支援感應支付的店家與交通工具也越來越多。

  4. 免稅

    外國旅客可享消費稅免稅制度。自2026年11月起，改為購物時先支付含稅價格，出境時經確認後退稅的方式。手續請在店內確認。

旅行小提醒

日本沒有給小費的習慣。結帳時，請把現金或卡片放在收銀台的小托盤上。
