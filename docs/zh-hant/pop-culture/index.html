不只是風景的日本

流行文化

動漫、遊戲、最新科技。整座城市就是一場娛樂。

動畫、漫畫與遊戲已經成為到日本旅行的一大理由。從專門店街到美術館、數位藝術，在城市的各個角落都能遇見。

重點

  1. 秋葉原（東京）

    以電器街起家，如今聚集了動畫、遊戲與公仔的專門店。

  2. 中野Broadway（東京）

    整棟樓裡擠滿了販售二手漫畫、動畫書籍與稀有周邊的小店。

  3. 三鷹之森吉卜力美術館（東京）

    可以沉浸在吉卜力工作室世界中的美術館。採指定日期與時間的預約制，不販售當日票。

  4. teamLab美術館（東京）

    被光與影像包圍的沉浸式數位藝術。人氣很高，建議事先預約。

旅行備忘

旅行小提醒

熱門設施在一個多月前就會額滿。店內拍照請先確認是否允許；造訪作品取景地時，請顧及當地居民的生活。
