依季節探索

秋

從山間染到村落的紅葉

紅葉從北海道的山間開始，慢慢向南推移。京都寺院庭園染成紅黃兩色，大約在11月下旬。

看點

  1. 日光（栃木）

    中禪寺湖與伊呂波坂在10月中旬至下旬最美，東照宮周邊則在11月上旬。道路容易壅塞，建議清晨出發。

  2. 東福寺（京都）

    從通天橋俯瞰，整個溪谷被紅葉染紅。最佳觀賞期為11月下旬。

  3. 奧入瀨溪流（青森）

    可以沿著溪流，在染成黃色與紅色的樹下漫步。最佳觀賞期為10月中旬至下旬。

  4. 香嵐溪（愛知）

    約4,000棵楓樹妝點溪谷，是東海地區首屈一指的紅葉名所。11月中旬至下旬最美，夜間有點燈活動。

旅行備忘

最佳時期
10月～12月上旬
推薦景點
日光（栃木）、東福寺（京都）、奧入瀨溪流（青森）
穿著
10月穿長袖襯衫，11月需要夾克或毛衣。山區比市區更冷。

旅行小提醒

紅葉由北向南、從山頂向山腳推進。名所建議在平日或清晨前往。11月的京都住宿一房難求，請儘早預訂。
