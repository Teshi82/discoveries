富士山、富士五湖

倒映湖面，雲霧繚繞。去看日本最高的山。

海拔3,776公尺的富士山於2013年登錄為世界文化遺產。北麓的富士五湖是隔湖遠眺富士山的絕佳地點。即使不登山，只要換個觀景點，也能玩上一整天。

看點

  1. 河口湖

    富士五湖的門戶。無風的清晨，湖面上會出現「逆富士」。北岸的大石公園可以同時欣賞花海與富士山。

  2. 新倉山淺間公園

    登上398級階梯，就能抵達將五重塔與富士山收進同一畫面的觀景台。櫻花季節尤其受歡迎。

  3. 忍野八海

    富士山的融雪經過漫長歲月滲透後湧出，形成八座池塘。池水清澈見底，令人印象深刻。

  4. 富士山五合目與登山

    登山道通常在7月上旬至9月上旬開放。設有通行費與入山管制，規劃前請先確認官方網站。

旅行備忘

最佳時期
空氣清澈的11月至隔年2月最容易看到富士山。4月可與櫻花同框，11月上旬至中旬可與紅葉同框。
交通
從新宿到河口湖，搭高速巴士約1小時45分鐘，搭特急「富士回遊」約2小時。
建議停留
1～2天。想看清晨的富士山，建議在湖畔住一晚。

旅行小提醒

下午容易起雲，清晨是最佳時機。出發前透過即時影像確認山的狀況會更安心。
