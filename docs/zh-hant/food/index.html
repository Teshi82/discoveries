不只是風景的日本

美食

壽司、拉麵、鄉土料理。從路邊小攤到百年老店，品嚐季節與土地的味道。

日本的飲食因地域與季節而大不相同。2013年，「和食」登錄為聯合國教科文組織無形文化遺產。不只是高級餐廳，車站便當、百貨公司的美食街和便利商店裡也有驚喜。

重點

  1. 壽司

    從平價的迴轉壽司，到師傅在眼前捏製的板前店。板前店一般需要預約，並以「Omakase」（無菜單料理）的方式點餐。

  2. 拉麵

    札幌的味噌、博多的豚骨、東京的醬油，各地風味不同。很多店需要在門口的售票機購買餐券。

  3. 居酒屋

    一邊分享小碟料理一邊喝酒的店。有時會送上一道名為「Otoshi」的小菜，代替座位費。

  4. 鄉土料理與市場

    大阪的章魚燒、廣島的牡蠣、北海道的海鮮丼。各地的市場從清晨起就能品嚐當地風味。

旅行備忘

旅行小提醒

不需要給小費。街頭小吃請在店門口或指定區域享用，不要邊走邊吃。有過敏或素食需求的人請事先告知店家，蔬菜料理也可能使用魚高湯。
