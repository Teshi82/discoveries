北日本

北海道

夏は花の丘、冬は粉雪。季節ごとに別の顔を見せる北の大地。

日本の面積の約5分の1を占める北海道は、広い空とまっすぐな道、手つかずの自然が魅力です。夏は涼しく、冬はたっぷりと雪が積もります。見どころ同士が離れているので、エリアを絞って計画しましょう。

見どころ

  1. 富良野・美瑛

    7月中旬に見頃を迎えるラベンダー畑と、畑が模様を描く「パッチワークの丘」。美瑛の「青い池」も人気です。

  2. 知床

    2005年に世界自然遺産に登録された半島。夏は知床五湖の散策や観光船、冬はオホーツク海の流氷が見られます。

  3. ニセコ

    世界中のスキーヤーが集まるパウダースノーの聖地。夏は羊蹄山を望むラフティングやハイキングが楽しめます。

  4. 札幌・小樽

    2月上旬の「さっぽろ雪まつり」と、石造り倉庫が並ぶ小樽運河。味噌ラーメンや海鮮など食の楽しみも豊富です。

旅のメモ

ベストシーズン
花と丘の風景は6月〜8月、雪とウィンタースポーツは12月〜3月。紅葉は9月中旬に大雪山から始まります。
アクセス
東京（羽田）から新千歳空港まで約1時間30分。空港から札幌へは快速列車で約40分です。
滞在の目安
4〜7日。1回の旅では、道央・道東など1〜2エリアに絞るのがおすすめ。

旅のヒント

地図で見るより距離があります。札幌から富良野まで車で約2時間、知床までは約6時間。冬の雪道運転に慣れていない場合は、鉄道やバスを利用しましょう。
