6日間

北の大地ドライブ

レンタカーで巡る花畑と丘、そして世界自然遺産・知床の原生の自然。

札幌を出発して東へ。花畑、湖、原生林へと景色が移り変わるドライブルートです。走行距離は合計600kmほど。最後は女満別空港でレンタカーを返すと、来た道を戻らずに済みます。

旅程

  1. 札幌（1日目）

    市内を観光し、味噌ラーメンや海鮮を味わいます。翌朝レンタカーを借りて出発。

  2. 富良野・美瑛（2〜3日目）

    札幌から車で約2時間。ラベンダー畑、パッチワークの丘、青い池をゆっくり巡ります。

  3. 阿寒湖（4日目）

    美瑛から約4時間のロングドライブ。マリモで知られる湖畔の温泉街に泊まり、アイヌ文化にも触れられます。

  4. 知床（5〜6日目）

    阿寒湖から約2時間30分。知床五湖の散策や観光船で、原生の自然を体感します。女満別空港まではウトロから約2時間。

旅のメモ

ベストシーズン
花の見頃は6月下旬〜8月（ラベンダーは7月）。紅葉は9月下旬〜10月です。
移動手段
レンタカーを利用します。日本は左側通行。海外の免許で運転するには国際運転免許証が必要で、国によっては免許証の日本語翻訳文が求められます。

旅のヒント

朝夕はエゾシカやキタキツネが道路に飛び出すことがあります。野生動物に餌を与えないでください。ガソリンスタンドの少ない区間があるので、給油は早めに。
