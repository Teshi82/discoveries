日本を旅する

四季が描く、日本の絶景へ。

雪をいただく山々、千年の都、珊瑚の海。列島を旅して出会う風景を、地域と季節からご案内します。

旅先を探す

地域から探す

北から南まで、およそ3,000kmに連なる列島。土地ごとにまったく違う表情があります。

関西

京都

池に映る金閣寺、朱の鳥居が続く伏見稲荷、竹林の嵐山、東山の石畳。千年の都は早朝がいちばん美しい。

山梨・静岡

富士山・富士五湖

湖面に映る逆さ富士、茶畑越しの山容。眺める場所ごとに違う顔を見せる日本の象徴。

北日本

北海道

夏は富良野・美瑛の花畑と丘、冬は世界が憧れるパウダースノー。雄大な自然が広がる北の大地。

南西諸島

沖縄・慶良間諸島

「ケラマブルー」と呼ばれる透明な海と白い砂浜。琉球王国の文化が息づく南の島々。

中国・四国

瀬戸内

穏やかな海に浮かぶ多島美。しまなみ海道のサイクリングと、直島のアートを巡る旅。

本州北部

東北

奥入瀬渓流の新緑、蔵王の樹氷、ひなびた湯治場。静かな日本の原風景が残る地域。

季節から探す

同じ場所でも、訪れる季節で風景は一変します。

桜前線を追いかけて

桜は3月下旬に九州から咲きはじめ、5月上旬に北海道へ。開花は年により前後するため、最新の開花予想の確認を。

見頃
3月下旬〜5月上旬
おすすめ
吉野山（奈良）・弘前公園（青森）・目黒川（東京）

祭りと花火、高原の涼

夜空を彩る花火大会と各地の夏祭り。暑さを避けるなら上高地や北海道など、標高や緯度の高い場所へ。

見頃
7月〜8月
おすすめ
上高地（長野）・青森ねぶた祭・富良野（北海道）

山から里へ降りる紅葉

紅葉は北海道の山から始まり、ゆっくりと南下します。寺社の庭園が赤や黄に染まる京都は11月下旬が目安。

見頃
10月〜12月上旬
おすすめ
日光（栃木）・東福寺（京都）・奥入瀬渓流（青森）

雪景色と温泉

合掌造りの集落に積もる雪、露天風呂から眺める雪見。空気が澄む冬は、富士山がもっともよく見える季節です。

見頃
12月〜2月
おすすめ
白川郷（岐阜）・ニセコ（北海道）・銀山温泉（山形）

モデルコース

初めての方にも、二度目の方にも。旅の計画としてお使いください。

  1. 7日間

    ゴールデンルート

    初めての日本に。都市の活気、富士山、古都を一度に味わう定番コース。

    東京 → 箱根・富士 → 京都 → 奈良 → 大阪

  2. 6日間

    北の大地ドライブ

    レンタカーで巡る花畑と丘、そして世界自然遺産・知床の原生の自然。

    札幌 → 富良野・美瑛 → 阿寒湖 → 知床

  3. 5日間

    瀬戸内アートと島旅

    平和への祈り、海に立つ大鳥居、島々を結ぶ橋とアート。

    広島 → 宮島 → 尾道・しまなみ海道 → 直島

風景だけじゃない日本

絶景の先には、受け継がれてきた伝統と最先端の文化、そして土地ごとの味が待っています。

食

寿司、ラーメン、郷土料理。季節と土地の味を、屋台から老舗まで。

伝統文化

城、社寺、着物、祭り。長く受け継がれてきた美意識に触れる。

ポップカルチャー

アニメ、ゲーム、最新テクノロジー。街そのものがエンターテインメント。

温泉

全国各地に湧く温泉。雪見風呂や、湯に浸かる野生の猿に出会える場所も。

旅の基本情報

移動

都市間は新幹線が速くて正確。交通系ICカードがあれば、電車・バス・買い物まで一枚で済みます。

支払い

カードやスマホ決済は広く使えますが、地方の小さな店や寺社では現金が必要なこともあります。

マナー

電車内での通話は控えめに。温泉では湯船に入る前に体を洗い、タオルは湯に浸けません。

通信

eSIMやポケットWi‑Fiが便利。空港や主要駅には無料Wi‑Fiもあります。
