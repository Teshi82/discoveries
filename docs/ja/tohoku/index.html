本州北部

東北

渓流と雪と湯けむり。静かな日本の原風景へ。

本州の北に広がる東北6県は、深い森と山、ひなびた温泉、力強い夏祭りの土地です。大都市に比べて旅行者が少なく、ゆっくりと自然や暮らしの風景に向き合えます。

見どころ

  1. 奥入瀬渓流・十和田湖

    十和田湖から流れ出る約14kmの渓流。苔むした岩と滝を眺めながら歩ける遊歩道が、流れに沿って続きます。

  2. 蔵王

    冬は「スノーモンスター」と呼ばれる樹氷がゲレンデを覆い、1月〜2月が見頃です。夏はエメラルド色の火口湖「御釜」へ。

  3. 松島

    260あまりの島々が浮かぶ日本三景のひとつ。遊覧船で湾を巡り、伊達政宗ゆかりの瑞巌寺を訪ねます。

  4. 銀山温泉

    川の両岸に大正〜昭和初期の木造旅館が並ぶ温泉街。ガス灯がともる夕暮れと雪の季節は、とりわけ風情があります。

旅のメモ

ベストシーズン
新緑は5月〜6月、夏祭りは8月上旬、紅葉は10月、樹氷は1月〜2月。季節ごとに目的地を選ぶのがコツです。
アクセス
東京から新幹線で仙台まで約1時間30分、新青森まで約3時間10分です。
滞在の目安
3〜5日。県をまたぐ移動に時間がかかるので、1回の旅では2〜3県に絞ると無理がありません。

旅のヒント

駅から先のバスは本数が少ないので、時刻表を事前に確認するか、レンタカーを利用しましょう。8月上旬の祭りの時期は、宿を早めに予約してください。
