風景だけじゃない日本

温泉

全国各地に湧く温泉。雪見風呂や、湯に浸かる野生の猿に出会える場所も。

火山の多い日本には、3,000近い温泉地があります。温泉街をそぞろ歩き、宿で湯と食事を楽しむ一泊は、旅のなかでも特別な時間です。

ポイント

  1. 草津温泉（群馬）

    温泉街の中心に湯けむりを上げる「湯畑」があり、板で湯をかき混ぜる伝統の「湯もみ」も見られます。

  2. 別府温泉（大分）

    湧き出る湯の量は日本一。色とりどりの源泉を見て回る「地獄めぐり」が人気です。

  3. 城崎温泉（兵庫）

    柳並木の川沿いを浴衣と下駄で歩き、七つの外湯を巡る温泉街。

  4. 地獄谷野猿公苑（長野）

    湯に浸かる野生の猿を間近で観察できます。人が入る温泉は近くの渋温泉・湯田中温泉で。

旅のメモ

旅のヒント

湯船に入る前に体を洗い、タオルは湯に浸けません。長い髪は束ねましょう。タトゥーがあると入れない施設もあるので、貸切風呂や受け入れのある施設を事前に確認してください。
