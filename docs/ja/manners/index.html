旅の基本情報

マナー

電車内での通話は控えめに。温泉では湯船に入る前に体を洗い、タオルは湯に浸けません。

難しい決まりはありません。まわりの人の邪魔にならないように、という気づかいが基本です。迷ったら、周囲の人の様子に合わせれば大丈夫。

ポイント

  1. 電車やバスで

    通話は控え、会話は小さな声で。リュックは前に抱え、乗るときは列に並びます。

  2. 靴を脱ぐ

    旅館、寺、民家では入口で靴を脱ぎます。畳の部屋ではスリッパも脱ぎましょう。

  3. ごみ

    街なかにはごみ箱がほとんどありません。小さな袋を持ち歩き、宿に持ち帰って捨てます。

  4. 温泉と銭湯

    湯船に入る前に体を洗い、タオルは湯に浸けません。浴室での撮影は禁止です。

旅のヒント

人や私有地を無断で撮影しないようにしましょう。京都の祇園には、立ち入りや撮影が禁止されている私道があります。
