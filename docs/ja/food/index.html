風景だけじゃない日本

食

寿司、ラーメン、郷土料理。季節と土地の味を、屋台から老舗まで。

日本の食は、土地と季節で大きく変わります。2013年には「和食」がユネスコ無形文化遺産に登録されました。高級店だけでなく、駅弁やデパートの食品売り場、コンビニにも発見があります。

ポイント

  1. 寿司

    手頃な回転寿司から、職人が目の前で握るカウンターの店まで。カウンターの店は予約をして、「おまかせ」で頼むのが一般的です。

  2. ラーメン

    札幌の味噌、博多の豚骨、東京の醤油など、土地ごとに味が違います。入口の券売機で食券を買う店が多くあります。

  3. 居酒屋

    小皿料理を分け合いながら酒を楽しむ店。席料の代わりに「お通し」と呼ばれる小鉢が出ることがあります。

  4. 郷土料理と市場

    大阪のたこ焼き、広島の牡蠣、北海道の海鮮丼。各地の市場は、朝から土地の味を楽しめる場所です。

旅のメモ

旅のヒント

チップは不要です。食べ歩きは歩きながらではなく、買った店の前や決められた場所で。アレルギーや菜食の方は事前に店へ伝えましょう。野菜料理でも魚のだしを使うことがあります。
