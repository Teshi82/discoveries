季節から探す

秋

山から里へ降りる紅葉

紅葉は北海道の山から始まり、ゆっくりと南下します。寺社の庭園が赤や黄に染まる京都は11月下旬が目安。

見どころ

  1. 日光（栃木）

    中禅寺湖といろは坂は10月中旬〜下旬、東照宮の周辺は11月上旬が見頃。道路が混むので早朝の出発を。

  2. 東福寺（京都）

    通天橋から見下ろす渓谷が一面の紅葉に染まります。見頃は11月下旬。

  3. 奥入瀬渓流（青森）

    流れに沿って黄や赤に色づく木々の下を歩けます。見頃は10月中旬〜下旬。

  4. 香嵐渓（愛知）

    約4,000本のもみじが渓谷を彩る東海地方随一の名所。11月中旬〜下旬が見頃で、夜はライトアップされます。

旅のメモ

見頃
10月〜12月上旬
おすすめ
日光（栃木）・東福寺（京都）・奥入瀬渓流（青森）
服装
10月は長袖シャツ、11月はジャケットやセーターが目安です。山あいは街より冷え込みます。

旅のヒント

紅葉は北から南へ、山の上から麓へと進みます。名所は平日か朝早くがおすすめ。11月の京都は宿が取りにくいので早めの予約を。
