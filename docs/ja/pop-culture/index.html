風景だけじゃない日本

ポップカルチャー

アニメ、ゲーム、最新テクノロジー。街そのものがエンターテインメント。

アニメ、マンガ、ゲームは、日本を旅する大きな理由のひとつになりました。専門店街から美術館、デジタルアートまで、街のあちこちで出会えます。

ポイント

  1. 秋葉原（東京）

    電気街として発展し、いまはアニメ、ゲーム、フィギュアの専門店が集まる街。

  2. 中野ブロードウェイ（東京）

    マンガやアニメの古書、希少なグッズを扱う小さな店がビルいっぱいに並びます。

  3. 三鷹の森ジブリ美術館（東京）

    スタジオジブリの世界に浸れる美術館。日時指定の予約制で、当日券はありません。

  4. チームラボのミュージアム（東京）

    光と映像に包まれる体験型のデジタルアート。人気が高いので事前予約がおすすめです。

旅のメモ

旅のヒント

人気の施設は1か月以上前から予約が埋まります。店内の撮影は可否を確認し、作品の舞台を訪ねるときは住民の暮らしに配慮しましょう。
