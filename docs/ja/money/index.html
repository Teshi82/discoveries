旅の基本情報

支払い

カードやスマホ決済は広く使えますが、地方の小さな店や寺社では現金が必要なこともあります。

通貨は円です。キャッシュレス決済が広がっていますが、現金しか使えない場面も残っています。両方を用意しておくと安心です。

ポイント

  1. 現金

    小さな飲食店、寺社の拝観料、地方のバスなどでは現金が必要になることがあります。

  2. ATM

    コンビニや郵便局のATMでは、海外発行のカードで円を引き出せます。

  3. カードとスマホ決済

    ホテル、百貨店、チェーン店ではほぼ使えます。タッチ決済に対応した店や交通機関も増えています。

  4. 免税

    外国人旅行者向けに消費税の免税制度があります。2026年11月からは、購入時に税込みで支払い、出国時の確認後に返金を受ける方式になりました。手続きは店頭で確認を。
