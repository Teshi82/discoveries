富士山・富士五湖

湖に映り、雲をまとう。日本でいちばん高い山を眺める旅。

標高3,776mの富士山は、2013年に世界文化遺産に登録されました。北麓に並ぶ富士五湖は、湖越しに山を望む絶好の場所。登らなくても、眺める場所を変えるだけで一日楽しめます。

見どころ

  1. 河口湖

    富士五湖の玄関口。風のない朝には湖面に「逆さ富士」が現れます。北岸の大石公園は花と富士を一緒に眺められる場所です。

  2. 新倉山浅間公園

    五重塔と富士山が一枚に収まる展望デッキへは、398段の階段を上ります。桜の季節はとりわけ人気です。

  3. 忍野八海

    富士山の雪解け水が長い歳月をかけて湧き出す八つの池。底まで見通せるほど澄んだ水が印象的です。

  4. 富士山五合目と登山

    登山道が開くのは例年7月上旬〜9月上旬。通行料や入山規制があるので、計画の前に公式サイトを確認してください。

旅のメモ

ベストシーズン
山がよく見えるのは空気の澄む11月〜2月。4月は桜、11月上旬〜中旬は紅葉と一緒に眺められます。
アクセス
新宿から河口湖まで、高速バスで約1時間45分、特急「富士回遊」で約2時間です。
滞在の目安
1〜2日。朝の富士を見るなら湖畔に1泊を。

旅のヒント

雲は午後に出やすいので、早朝がいちばんの狙い目。出発前にライブカメラで山の様子を確かめると安心です。
