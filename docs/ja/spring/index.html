季節から探す

春

桜前線を追いかけて

桜は3月下旬に九州から咲きはじめ、5月上旬に北海道へ。開花は年により前後するため、最新の開花予想の確認を。

見どころ

  1. 吉野山（奈良）

    約3万本の桜が、山裾から山上へと順に咲き上がります。見頃は4月上旬〜中旬。

  2. 弘前公園（青森）

    弘前城を囲む桜と、散った花びらが堀を埋める「花筏」で知られます。見頃は4月下旬ごろ。

  3. 目黒川（東京）

    約4kmの川沿いに約800本の桜が続く、都心の花見の名所。3月下旬〜4月上旬が見頃です。

  4. 国営ひたち海浜公園（茨城）

    4月中旬〜5月上旬、ネモフィラが丘一面を青く染めます。桜のあとに訪れたい春の風景。

旅のメモ

見頃
3月下旬〜5月上旬
おすすめ
吉野山（奈良）・弘前公園（青森）・目黒川（東京）
服装
朝晩は冷えるので、薄手の上着や重ね着が便利です。3月は冬のコートが必要な日もあります。

旅のヒント

満開の時期は1週間ほど。日程が決まっているなら、開花の早い南か遅い北かで行き先を選びましょう。4月末〜5月上旬の大型連休はどこも混み合います。
