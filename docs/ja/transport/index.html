旅の基本情報

移動

都市間は新幹線が速くて正確。交通系ICカードがあれば、電車・バス・買い物まで一枚で済みます。

日本の鉄道は路線が細かく張り巡らされ、時刻も正確です。都市の間は新幹線、街のなかは電車と地下鉄を使うのが基本になります。

ポイント

  1. 新幹線

    東京〜新大阪は最速で約2時間30分。指定席は駅の窓口・券売機やインターネットで予約できます。

  2. 交通系ICカード

    SuicaやICOCAなどは全国の主要都市で相互に使え、スマートフォンに入れて使うこともできます。

  3. ジャパン・レール・パス

    短期滞在の旅行者向けの、JR線が乗り放題になる切符。「のぞみ」「みずほ」に乗るには追加料金が必要です。

  4. 高速バスと国内線

    夜行バスは費用を抑えたいときに便利。北海道、九州、沖縄へは飛行機が早く着きます。

旅のヒント

平日の朝7時30分〜9時30分ごろは通勤ラッシュです。大きな荷物を持っての移動は、この時間帯を避けましょう。
