中国・四国

瀬戸内

穏やかな海と島々を、橋と船でつないで旅する。

本州・四国・九州に囲まれた瀬戸内海には、大小さまざまな島が浮かびます。雨が少なく温暖な気候で、海辺の町には古い港や町並みが残ります。自転車と船、そして現代アートがこの地域の旅の主役です。

見どころ

  1. しまなみ海道

    広島県の尾道と愛媛県の今治を、6つの島と橋で結ぶ約70kmのサイクリングロード。レンタサイクルは途中の島で返却できます。

  2. 直島

    安藤忠雄が設計した地中美術館や、海辺に置かれた草間彌生の「南瓜」で知られるアートの島。岡山県の宇野港からフェリーで約20分です。

  3. 宮島・嚴島神社

    満潮時には海に浮かんで見える朱色の大鳥居と社殿。干潮時には鳥居のそばまで歩けます。世界遺産に登録されています。

  4. 倉敷美観地区

    柳並木の堀に沿って白壁の蔵屋敷が続く町並み。日本初の私立西洋美術館、大原美術館もここにあります。

旅のメモ

ベストシーズン
過ごしやすいのは春（3月〜5月）と秋（10月〜11月）。3年に1度開かれる瀬戸内国際芸術祭の年は、島々がいっそう賑わいます。
アクセス
東京から新幹線で岡山まで約3時間20分、広島まで約4時間。島へは各地の港からフェリーや高速船で渡ります。
滞在の目安
3〜5日。直島としまなみ海道の両方を巡るなら4日以上がおすすめ。

旅のヒント

美術館は月曜休館が多く、地中美術館は事前予約制です。フェリーは本数が限られるので、帰りの時刻を先に確かめておきましょう。
