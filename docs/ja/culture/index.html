風景だけじゃない日本

伝統文化

城、社寺、着物、祭り。長く受け継がれてきた美意識に触れる。

城や社寺、祭りは、いまも暮らしのなかで受け継がれています。眺めるだけでなく、作法を知り、体験に参加すると旅の印象が深まります。

ポイント

  1. 城

    江戸時代以前の天守が残る城は全国に12。白い外観から「白鷺城」と呼ばれる世界遺産の姫路城や、黒い天守の松本城が代表です。

  2. 神社と寺

    神社では鳥居の前で一礼し、手水で手と口を清め、二礼二拍手一礼で参拝します。寺では手をたたかず、静かに合掌を。

  3. 祭り

    7月の京都・祇園祭、8月の青森ねぶた祭、春と秋の高山祭など。山車や神輿が町を巡ります。

  4. 体験

    茶道、着物の着付け、座禅、寺に泊まる宿坊など。高野山では朝のお勤めに参加できます。

旅のヒント

建物に上がるときは靴を脱ぎます。撮影禁止の表示に従い、祈っている人の邪魔にならないようにしましょう。
