旅の基本情報

通信

eSIMやポケットWi‑Fiが便利。空港や主要駅には無料Wi‑Fiもあります。

地図、乗り換え案内、翻訳。旅先ではスマートフォンが頼りになります。到着してすぐ使えるように、出発前に通信手段を決めておきましょう。

ポイント

  1. eSIM

    出発前にオンラインで購入・設定しておけば、到着後すぐに使えます。対応機種かどうかを確認してください。

  2. ポケットWi‑Fi

    1台で複数の端末をつなげるので、グループや家族での旅に向いています。空港で受け取りと返却ができます。

  3. 無料Wi‑Fi

    空港、主要駅、ホテル、カフェで使えます。山間部や離島では電波が届きにくい場所もあります。

  4. 電源

    電圧は100V、プラグは平たい2本ピンのAタイプ。変換プラグが必要かどうかを確認しましょう。
