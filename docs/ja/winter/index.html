季節から探す

冬

雪景色と温泉

合掌造りの集落に積もる雪、露天風呂から眺める雪見。空気が澄む冬は、富士山がもっともよく見える季節です。

見どころ

  1. 白川郷（岐阜）

    世界遺産の合掌造り集落が雪に包まれます。1月〜2月の特定日に行われるライトアップは予約制です。

  2. ニセコ（北海道）

    12月〜3月、軽くて乾いたパウダースノーを求めて世界中からスキーヤーが集まります。

  3. 銀山温泉（山形）

    木造旅館が並ぶ温泉街に雪が積もり、ガス灯がともる夕暮れは別世界のよう。

  4. 地獄谷野猿公苑（長野）

    温泉に浸かる野生のニホンザルに出会える場所。入口から雪の山道を30分ほど歩きます。

旅のメモ

見頃
12月〜2月
おすすめ
白川郷（岐阜）・ニセコ（北海道）・銀山温泉（山形）
服装
防寒コート、手袋、滑りにくい靴を。室内は暖房が効いているので、脱ぎ着しやすい重ね着が向いています。

旅のヒント

12月29日〜1月3日ごろは休業する店や施設が多くなります。雪で列車や飛行機が遅れることもあるので、日程に余裕を持ちましょう。
