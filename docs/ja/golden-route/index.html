ホーム/モデルコース

7日間

ゴールデンルート

初めての日本に。都市の活気、富士山、古都を一度に味わう定番コース。

東京から西へ、新幹線の沿線をたどる王道のルートです。乗り換えが少なく、初めての日本でも計画しやすいのが魅力。帰りは関西国際空港から出国すると、東京へ戻る時間を省けます。

旅程

  1. 東京（1〜3日目）

    浅草、渋谷、皇居周辺など、新旧の街を歩きます。到着日は時差もあるので予定を詰めすぎずに。

  2. 箱根・富士（4日目）

    新宿から特急ロマンスカーで箱根湯本まで約1時間25分。温泉宿に泊まり、晴れれば芦ノ湖の向こうに富士山が見えます。

  3. 京都（5〜6日目）

    小田原から新幹線で約2時間。金閣寺、伏見稲荷、東山などをエリアごとに巡ります。

  4. 奈良（6日目の午後）

    京都から電車で約45分。東大寺の大仏と、鹿が歩く奈良公園を訪ねる半日旅です。

  5. 大阪（7日目）

    京都から電車で約30分。道頓堀で食べ歩きを楽しみ、関西国際空港から帰路へ。

旅のメモ

ベストシーズン
桜の3月下旬〜4月と、紅葉の10月〜11月が人気です。夏は蒸し暑くなります。
移動手段
新幹線と在来線で移動できます。ジャパン・レール・パスは、区間ごとに切符を買う場合と料金を比べて選びましょう。

旅のヒント

大きな荷物は宅配便で次の宿へ送ると身軽に動けます（翌日着が基本）。新幹線に特大サイズの荷物を持ち込む場合は、事前の座席予約が必要です。
