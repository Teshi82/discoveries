5日間

瀬戸内アートと島旅

平和への祈り、海に立つ大鳥居、島々を結ぶ橋とアート。

広島から東へ、瀬戸内海に沿って進むルートです。歴史をたどる街歩き、海の上の神社、自転車で渡る橋、島のアートと、毎日違う楽しみがあります。

旅程

  1. 広島（1日目）

    平和記念公園と原爆ドームを訪ね、平和について考える一日。夜は広島風お好み焼きを。

  2. 宮島（2日目）

    広島駅から電車とフェリーで約1時間。嚴島神社と大鳥居、ロープウエーで登る弥山からの眺めを楽しみます。

  3. 尾道・しまなみ海道（3日目）

    広島から尾道まで電車で約1時間30分。坂と寺の町を歩き、自転車で橋を渡って島へ。

  4. 直島（4〜5日目）

    岡山を経由して宇野港へ行き、フェリーで約20分。美術館と屋外作品を巡り、島に泊まります。

旅のメモ

ベストシーズン
気候の穏やかな4月〜5月と10月〜11月がおすすめです。
移動手段
鉄道、フェリー、レンタサイクルを組み合わせます。

旅のヒント

直島の美術館は月曜休館が多く、予約が必要な施設もあります。宮島は潮の満ち引きで景色が変わるので、潮見表を確認してから出かけましょう。
