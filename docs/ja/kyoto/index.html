関西

京都

千年の都を、朝の静けさのなかで歩く。

794年から千年以上にわたって都が置かれた京都には、世界遺産の社寺や庭園、町家の続く路地がいまも息づいています。見どころは市内各所に点在しているので、エリアごとに1日ずつあてると無理なく巡れます。

見どころ

  1. 金閣寺

    金箔に覆われた舎利殿が鏡湖池に映る、京都を代表する風景。晴れた日の午前は池の映り込みがひときわ鮮やかです。

  2. 伏見稲荷大社

    朱色の鳥居が山の上まで連なる千本鳥居。稲荷山をひと回りすると約2時間、上へ行くほど人が少なくなります。

  3. 嵐山

    竹林の小径と、桂川に架かる渡月橋。春の桜と秋の紅葉の時期は山全体が色づきます。

  4. 清水寺と東山

    崖にせり出す「清水の舞台」から市街を一望。二年坂・産寧坂の石畳には昔ながらの町並みが続きます。

旅のメモ

ベストシーズン
桜は3月下旬〜4月上旬、紅葉は11月中旬〜12月上旬。新緑の5月や雪化粧の冬は比較的落ち着いて歩けます。
アクセス
東京から新幹線で約2時間15分。関西国際空港からは特急「はるか」で約1時間20分です。
滞在の目安
2〜3日。奈良や宇治へ足をのばすなら、もう1日。

旅のヒント

人気の社寺は開門直後の早朝がおすすめ。市バスは混みやすいので、地下鉄や電車と徒歩を組み合わせるとスムーズです。
