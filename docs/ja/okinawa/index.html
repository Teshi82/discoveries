南西諸島

沖縄・慶良間諸島

透きとおる海と、琉球の文化に出会う南の島。

亜熱帯の気候に包まれた沖縄は、かつて琉球王国として独自の文化を育んだ島々です。那覇を拠点に、船で渡る慶良間の海、本島北部の自然、さらに南の八重山へと旅が広がります。

見どころ

  1. 慶良間諸島

    那覇の泊港から高速船で渡嘉敷島へ約35分、座間味島へ約50分。国立公園の海ではウミガメと泳げることもあります。

  2. 首里城公園

    琉球王国の王城跡。正殿は2019年の火災で焼失し、復元が進められてきました。公開状況は公式サイトで確認を。

  3. 沖縄美ら海水族館

    ジンベエザメやマンタが泳ぐ大水槽「黒潮の海」で知られる水族館。那覇から車で約2時間、本島北部にあります。

  4. 石垣島・竹富島

    那覇から飛行機で約1時間の八重山諸島。川平湾の眺めと、赤瓦の家並みを水牛車で巡る竹富島が待っています。

旅のメモ

ベストシーズン
海で泳げるのは4月〜10月ごろ。梅雨は5月上旬〜6月下旬、台風は7月〜10月に多くなります。1月〜3月はホエールウォッチングの季節です。
アクセス
東京（羽田）から那覇まで約2時間45分。那覇空港から市の中心部へはモノレール「ゆいレール」で約15分です。
滞在の目安
3〜5日。離島に泊まるなら、もう1〜2日。

旅のヒント

台風や高波で船が欠航することがあるため、離島へ渡る日は旅の前半に。日差しが強いので日焼け対策を忘れず、サンゴには触れないようにしましょう。
